# IPTV Channel & Source Manager (IPTV 渠道与直播源管理系统)

这是一个功能齐全、现代化且极其轻量的 IPTV 渠道、轮播源和直播线路管理系统。采用前后端全栈架构设计，提供包括一键高并发测速与深度网络诊断、M3U/TXT 双格式导入导出、轮播频道与代理服务映射、AI 智能整理、EPG 电子节目单匹配、定时订阅拉取以及完整的 Web 工作台与接口订阅服务。

---

## 🚀 核心功能与亮点

- 🖥️ **现代化全响应式 Web 界面**：支持桌面端与移动端双向优化，卡片化布局，流畅交互体验。
- ⚡ **一键高并发测速与 H264/SPS 探测引擎**：支持多线路并发连通性与延迟测速，集成 HLS.js 实时画面预览与播放，自动探测 H.264 SPS 分辨率信息，支持快速一键筛选与清理失效线路。
- 🔍 **深度播放源诊断与报错抓包**：
  - 精确探测 0 字节空流、HTTP 404/500 异常状态码及非音视频网页/JSON 拦截。
  - 列表与卡片中为播放异常线路提供醒目的 **【⚠️ 诊断详情】** 按钮。
  - 提供现场重新深度诊断与服务器响应文本 (Response Snippet) 抓包查看功能，方便快速定位鉴权超时与防盗链问题。
- 🔀 **轮播频道与代理服务工作台**：
  - 统一管理虎牙、斗鱼、Bilibili、YY、抖音等平台的网络直播间与系统频道映射。
  - 内置特征匹配规则，可自动提取和识别同类直播源。
  - 提供轮播代理转换服务与专属 M3U/TXT 订阅导出接口。
- 📂 **M3U 与 TXT 双模灵活导入导出**：
  - 完美支持标准 M3U/TXT 文件的导入导出。
  - **精细导入规则配置**：可配置“禁止创建新频道”、“忽略分组”以及重名源覆盖逻辑，防止混淆已有频道结构。
  - **支持无源频道结构导入**：即使 M3U/TXT 文件仅包含频道元数据而没有直播链接，也能智能导入并创建/补充频道归属、Logo、别名与 EPG ID。
- 🏷️ **智能别名与归属解析**：自动匹配央视、卫视、港澳台等标准频道名称，解析 ISP 运营商及省份地理属性。
- 📺 **EPG 电子节目单整合**：支持本地与在线 XMLTV 格式 EPG 自动匹配与同步。
- 🤖 **AI 智能频道整理**：支持对接 DeepSeek、硅基流动、智谱 AI、阿里云、Moonshot、Gemini 等大模型，实现一键频道自动分类与别名补全。
- 🔄 **定时任务与订阅同步**：支持添加多个远程 M3U/TXT 订阅源并配置 Cron 定时拉取与自动更新任务。
- 💾 **SQLite 高性能持久化**：使用 SQLite 数据库存储数据，稳定防丢失，提供完整的 JSON/M3U 备份与恢复支持。

## 🛠️ 技术栈

- **前端**：React 19 + Vite 6 + Tailwind CSS v4 + Lucide React + Motion
- **后端**：Node.js 20 + Express 4 + Better-SQLite3
- **构建工具**：esbuild（生产环境打包单文件 CJS 捆绑包）
- **容器化**：Docker / Docker Compose

## 📦 部署与运行方法

### 方法一：使用 Docker Compose（推荐，生产部署）

系统内置完整的 `Dockerfile` 与 `docker-compose.yml`，非常适合部署在 Linux 服务器、群晖（Synology）等 NAS 设备中。

#### 1. 前置要求
- 安装并启动 `Docker` 与 `Docker Compose`。

#### 2. 一键启动
在项目根目录下执行：

```bash
docker compose up -d
```

#### 3. 访问与配置
- 启动成功后，通过浏览器访问：`http://localhost:3000`（或 `http://服务器IP:3000`）。
- **数据持久化**：本地挂载的 `./data` 目录将存储 SQLite 数据库及系统配置，容器更新时数据不丢失。
- **端口修改**：如需自定义端口，可编辑 `docker-compose.yml` 中的端口映射，例如 `"8080:3000"`。

---

### 方法二：本地开发与运行

#### 1. 环境准备
- Node.js 20.x 或更高版本。

#### 2. 安装依赖
```bash
npm install
```

#### 3. 启动开发模式
```bash
npm run dev
```

#### 4. 生产环境构建与启动
```bash
# 1. 编译打包前端与后端
npm run build

# 2. 启动生产服务器
npm run start
```

## 💡 使用指南

1. **频道与线路管理**：在“频道管理”工作台中可以添加、编辑频道，管理多条直播源线路，支持拖拽排序及分组划分。
2. **并发测速与深度诊断**：点击“一键检测”启动测速流，系统将探测 HTTP 连通性、Content-Type 及切片数据；遇到异常线路可点击【⚠️ 诊断详情】按钮查看抓包分析或现场重新诊断。
3. **轮播与代理映射**：在“轮播与代理”视图中添加各直播平台的房间号，配置特征发现规则，并可直接复制或订阅导出的轮播专属 M3U/TXT 播放链接。
4. **订阅与定时同步**：在“订阅管理”中配置远程 M3U/TXT 源以及更新频率，系统会自动抓取并增量更新频道线路。
5. **EPG 配置**：导入或指定 EPG 链接，系统会自动关联频道 `tvg-id`，为播放器提供完整的电子节目单指导。
